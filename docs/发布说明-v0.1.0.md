# v0.1.0 发布说明

## 发布结论

v0.1.0 是电商运营助手的首个 MVP 验收版。M0～M11 功能和 M12 发布门禁已完成，原需求 10 条验收标准均有自动化或可复现手工证据。

## 发布内容

- 可运行的 FastAPI API、Vue 3 前端和异步媒体 Worker。
- 12 个 Alembic 迁移版本，当前 head 为 `b1f7c92de340`，共33 张项目表。
- Dockerfile、前端 Nginx 镜像和 Docker Compose 编排。
- 三类 CSV 模板 API、幂等演示数据和完整演示讲稿。
- 58 项后端自动化测试、前端严格类型/生产构建、依赖审计和安全扫描。
- 发布打包脚本与 SHA-256 校验值。

## 升级要求

- Python 3.12+、Node.js 20+、MySQL 8.x；或 Docker Engine + Compose v2。
- 生产环境必须替换数据库密码、MySQL root 密码和 `JWT_SECRET`，关闭 `APP_DEBUG`。
- 在升级前同时备份 MySQL 和素材存储卷。
- 不使用 8000 端口；API 默认 8011，Docker 前端默认 8080。

## 已知限制

- 首版是单工作区、多店铺，不提供多租户数据隔离。
- 生产默认仍是本地/共享卷素材存储；多节点部署前需实现对象存储适配器。
- Worker 使用数据库队列，适用于首版中小规模；高吞吐场景需外部队列。
- 竞品解析只支持白名单公开链接，不绕过登录、验证码或平台风控。
- 投放模块只生成建议和实验计划，不创建真实广告、不扣费、不修改平台预算。
- 前端无障碍、多语言和移动端专项自动化尚未纳入首版门禁。
- 首次容器构建需要可用的 Docker Hub 或容器镜像源；本机当前配置的中科大镜像源返回 EOF，不影响本地脚本启动或发布包内容。

## 缺陷与豁免

- P0 已知未关闭缺陷：0。
- 书面豁免：无。
- P1/P2 限制：已在上述“已知限制”和原需求边界中公开。

## 回滚

使用发布前应用镜像/发布包回滚程序。若数据库不兼容，必须同时使用发布前的 MySQL 与素材卷备份；详见 `docs/部署升级与回滚.md`。
