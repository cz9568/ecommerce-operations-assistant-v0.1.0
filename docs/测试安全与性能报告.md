## 2. 功能与失败分支

- 认证：正确/错误密码、过期格式、退出撤销、停用用户和最后管理员保护。
- RBAC：管理员、运营人员、查看人员的读写边界，前端入口与后端 403 双重保护。
- 数据归属：跨商品 SKU、竞品、方案、素材、链接和实验 ID 被拒绝。
- 库存：事务同时修改库存与流水，乐观锁拒绝旧版本，禁止负库存和锁定量超限。
- AI Schema：五类严格 Schema、输入裁剪、结构修复、超时/限流/上游错误映射和失败不伪造业务记录。
- 任务：幂等创建、合法状态机、锁领取、取消竞争、指数退避、尝试上限、超时和过期锁恢复。
- 导入：只读预览、文件/行数/表头/编码限制、逐行保存点、部分成功、错误下载和上传/确认幂等。
- 完整 E2E：三角色登录后，从幂等演示数据遍历店铺、商品、SKU、库存、竞品、诊断、方案、任务、素材、链接、建议、实验、经营数据、复盘和下一轮诊断。

## 3. 安全与合规

| 范围 | 结论 |
|---|---|
| 鉴权与越权 | 业务 API 统一 Bearer 鉴权；高危写操作使用后端权限点；对象查询校验商品归属 |
| 密码与 Token | Argon2 强哈希；JWT 有过期时间和 JTI；退出后服务端撤销 |
| 输入 | Pydantic 类型/长度/枚举校验；SQLAlchemy 参数化查询；非法 Request ID 不回显 |
| URL/SSRF | 公开 HTTP(S) 协议、域名白名单、公网 IP、端口、重定向、超时、响应大小和验证码/登录挑战限制 |
| 文件 | 存储 Key 拒绝绝对路径与目录穿越；下载同时检查 MIME、文件签名、大小和 SHA-256 |
| 敏感信息 | `.env` 排除版本控制；平台授权元数据白名单；模型 Key 加密只写；日志/审计不保存明文凭证 |
| 隐私 | 点击 IP 仅保存 HMAC 摘要；机器人与 10 分钟重复点击留痕但不计入有效数 |
| 业务合规 | 不绕过登录/验证码，不自动创建广告、扣费或修改真实预算；投放建议必须人工确认 |

未发现高危未处理问题。

本机 Docker 镜像构建已进入基础镜像解析阶段，但当前配置的 `docker.mirrors.ustc.edu.cn` 镜像源返回 EOF，因此未在本机完成基础镜像下载。Compose 语法和发布结构已校验；正式发布时由 CI 或可访问 Docker Hub 的服务器完成镜像构建。

## 4. 性能与可靠性基线

首版定位为单工作区、中小团队。发布基线如下：

| 对象 | 基线 | 验证结果 |
|---|---|---|
| 列表 API | 必须分页，单页最大 100 | OpenAPI 与路由参数测试通过 |
| 工作台 | 查询数与返回条数无关，列表均有上限 | 认证 2 条 + 业务 11 条固定 SQL，无 N+1 |
| CSV 导入 | 最大 2MB/1000 行，预览 15 秒内 | 1000 行通过，1001 行在写业务表前拒绝 |
| 库存竞争 | 旧版本不得覆盖新值 | 第二个相同版本调整返回 409，库存/流水数量一致 |
| 点击 | 记录与累计同事务，防机器人/短时重复 | 3 次访问全部留痕，仅 1 次计入有效点击 |
| Worker | 并发 1～16，锁过期可恢复，超时进终态 | 重复运行不重复生成素材；超时、重试上限、取消竞争通过 |

本基线不是大促流量承诺。超过单工作区或需要高可用时，应在目标服务器上另做容量测试、对象存储和外部队列评估。
