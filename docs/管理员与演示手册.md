# 管理员与演示手册

## 1. 首次启用

1. 完成环境配置和数据库迁移。
2. 运行 `scripts/create-admin.ps1`，按提示输入管理员用户名、显示名和高强度密码。
3. 启动后端、前端和 Worker，访问 `http://127.0.0.1:5173`；Docker 默认访问 `http://127.0.0.1:8080`。
4. 首次登录后进入“用户管理”创建运营人员和查看人员。

## 2. 角色

| 角色 | 能力边界 |
|---|---|
| 管理员 | 全部业务操作、用户与角色、演示数据、模型/系统/队列设置 |
| 运营人员 | 店铺商品、库存、竞品、AI、任务、素材、投放与复盘；不能管理用户和系统设置 |
| 查看人员 | 只读查询业务数据，所有写操作由后端统一返回 403 |

系统会阻止停用或降级最后一名有效管理员。

## 3. 系统设置

- 模型 API Key 只写不读。页面显示“已配置”时，留空保存不会覆盖原值。
- “新请求立即生效”适用于文本模型和竞品解析。
- “重启 Worker 生效”适用于媒体 Provider、下载限制和队列调度参数。
- 数据库凭证、JWT 密钥和存储根目录是启动级安全配置，不能从网页修改。

## 4. 八分钟演示讲稿

1. **0:00～0:40 登录与权限**：分别说明管理员、运营人员、查看人员边界。
2. **0:40～1:10 初始化演示数据**：在空工作台或导入中心点击“初始化演示数据”；重复点击不会复制数据。
3. **1:10～2:00 商品底座**：从工作台进入【演示】店铺和商品，展示 SKU、库存、预警阈值和入库流水。
4. **2:00～2:40 竞品与诊断**：展示竞品公开字段、来源标识和七段结构化诊断。说明系统不绕过登录或验证码。
5. **2:40～3:30 创意与生成**：查看主图方案、选中状态、生成任务进度和事件时间线；演示成功与失败两种状态。
6. **3:30～4:20 素材审核**：展示素材版本、图片预览、通过/驳回、评分、场景和标签。
7. **4:20～5:20 链接与投放**：展示带 UTM 的推广链接、有效/过滤点击、八段投放建议及人工确认记录。强调系统不自动开广告或扣费。
8. **5:20～6:20 实验与经营数据**：展示已完成实验、曝光/点击/转化/花费/收入和统一 CTR、转化率、ROI 口径。
9. **6:20～7:10 复盘闭环**：查看复盘四段内容、版本时间线，并跳转到由该复盘开启的下一轮诊断。
10. **7:10～8:00 追溯与运维**：返回工作台，展示近期任务/复盘聚合；管理员打开系统设置，说明配置来源、密钥保护和生效方式。

## 5. 导入模板

导入中心提供商品、SKU/库存、经营数据三类 UTF-8 CSV 模板。单文件最大 2MB、最多 1000 个数据行。上传只生成预览，管理员/运营人员确认后才写入业务表；失败行可下载修正。

## 6. 常见问题

- **8011 无法启动**：先查看数据库就绪接口和数据库专用账号权限。
- **8000 被占用**：无需处理，本项目不使用 8000。
- **任务一直等待**：确认 Worker 已启动，再查看任务时间线和 Worker 日志。
- **修改队列参数未生效**：保存后重启 Worker。
- **素材无法预览**：在素材详情中执行文件检查，核对共享存储卷和 SHA-256 状态。
